# ✨ Starlight

### A responsive web interface built with HTML, CSS and JavaScript.

Starlight is a frontend web project focused on creating a visually polished and responsive user experience using traditional web technologies and Tailwind CSS.

The project explores interface structure, styling, reusable visual patterns, assets, and client-side behavior.

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* JSON
* Responsive Web Design

---

## 📁 Project Structure

```text
starlight
│
├── CSS/
├── Fonts/
├── HTML/
├── img/
├── js/
├── json/
├── .vscode/
├── index.html
├── styles.css
└── tailwind.config.js
```

The project separates markup, styling, JavaScript functionality, fonts, images, and supporting data to keep the frontend organized.

---

## 🎨 Frontend Focus

The project focuses on:

* Responsive layouts
* Visual hierarchy
* Custom styling
* Typography
* Asset organization
* Client-side interactions
* Structured HTML
* CSS-based interface design
* Reusable visual patterns

---

## 📱 Responsive Design

The interface was designed with different screen sizes in mind, adapting layouts and visual elements to provide a consistent experience across devices.

---

## 💻 Development

The project was developed using a modular frontend structure, with separate folders for HTML pages, CSS styles, JavaScript functionality, fonts, images, and JSON resources.

Tailwind CSS configuration is included through `tailwind.config.js`.
